Quick Start

Get up and running in minutes

1. Install PortPilot

pnpm add -D portpilot

2. Create .pilotrc.json

{
  "apps": [
    {
      "domain": "myapp.local",
      "port": 3000,
      "https": false
    }
  ],
  "on": {
    "stop": {
      "cleanNginx": true,
      "cleanHosts": true,
      "cleanConfigs": true
    }
  }
}

3. Run PortPilot

npx portpilot start
